# Личный сайт Артёма Коваленко

## Публикация статьи из My Zettel

1. Пишите исходную статью в My Zettel в Markdown (`.md`).
2. Скопируйте готовый текст в `_publications/unique-article-slug.md` этого репозитория. Образец заголовка файла — `templates/article.md`.
3. Заполните `title`, `description`, `date`, `lang` и `permalink`. Текст начинается после второго `---`. Языки статьи: `ru` или `en`; автоматического перевода текста нет.
4. Используйте обычные Markdown-ссылки вместо Obsidian `[[ссылок]]` и `![[вложений]]`. Картинки скопируйте в `assets/articles/unique-article-slug/` и вставьте как `![Описание](/assets/articles/unique-article-slug/image.jpg)`. Проверьте, что в экспорт не попали личные заметки.
5. Отправьте изменения в GitHub. В настройках GitHub Pages должен быть выбран режим **Deploy from a branch** и корень репозитория соответствующей ветки: Jekyll преобразует Markdown в HTML при публикации. Локальное сохранение файла само по себе сайт не обновляет.

Каталог статей: `/publications/`, с поиском по заголовку и описанию. Статьи автоматически добавляются в него по дате.

## Постоянные ссылки

Адрес задаёт `permalink`, например `/publications/unique-article-slug/`. После публикации его не меняйте и не используйте для другой статьи. Заголовок, оформление и имя Markdown-файла можно менять, сохраняя `permalink`. При переработке сайта сохраняйте обслуживание всех опубликованных адресов. Смена домена требует сохранения старого домена и перенаправлений; сам по себе permalink этого не обеспечивает.

Общее оформление статей: `_layouts/publication.html` и `assets/publications.css`. Шаблон в `templates/` не публикуется. Для черновиков храните тексты в My Zettel до готовности.
